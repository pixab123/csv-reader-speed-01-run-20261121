A fast, dependency-free, single-pass CSV reader for Node 22 that reproduces csv-reader 1.0.0's answers exactly — same columns, rows and error objects — at a fraction of its CPU time. `solve.js` exports `run(input)` → `{columns, rows, errors}`; `main.ts` is the harness driver that reads the cases, answers each with `run`, and writes the answers.

## Run it

```sh
node main.ts
```
